Parents, not the standard, decide what good with screens means. Six milestones give a parent, a guide and a researcher the same words, each paired with something a parent can see. Control tapers, and so does visibility: after Noticing, which apps the child uses is theirs alone. Sleep is the one screen-related harm with consistent replication across studies, so bedtime is protected first and handed over last. At sixteen there is nothing to switch off.
