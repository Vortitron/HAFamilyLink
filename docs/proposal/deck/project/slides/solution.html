The same five apps, the same child, the same room. The parent keeps the app they already have. Each vendor updates its own service to accept the plan. In the middle is the plan the parent wrote once: two hours, bedtime, school days. Each vendor’s service receives that plan and applies it on its own screens. Each reports back what it actually did. The parent sets the plan from whichever of the five they already use, because once certified, any of them can run the plan for the whole family. A family that prefers an independent app, a website or a home hub can use that instead. Matter did this for the smart home: Apple, Google and Amazon kept their own apps and agreed one language.
