Thank you for ten minutes. A parent holds one phone. On it is one plan for the family: how long, what, and when, from a first tablet at two to a first phone at fourteen. Every screen in the house follows that plan and reports back. That is Handrail. It is an open standard, and any company can build an app for it. A parent installs it by choice. Nobody needs ID to set it up or to switch it off.
