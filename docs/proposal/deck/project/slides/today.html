This is where parents are now. Five islands. Each company gives you a timer, a bedtime and a lock, for its own devices only. Family Link counts per device, so two hours means two hours on each. Apple’s Screen Time speaks to nothing outside Apple. Microsoft cannot see the Switch. No other vendor’s app can see the PlayStation. Of eleven tools we checked, nine can set a daily limit and not one can see another vendor’s device or let a parent join them. None of them knows there is one child, only devices.
