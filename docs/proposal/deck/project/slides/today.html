Where parents are today

A parent runs five apps, and none can see the others

Google Family Link

Limits per device. Two hours means two hours on each.

Apple Screen Time

Lives on the device. Speaks to nothing else.

Microsoft Family Safety

Instant lock removed without notice.

Nintendo parent app

Daily limit, bedtime, allow list. Its own island.

PlayStation Family

No interface beyond the console and the app.

The same basic controls five times over: a limit, a bedtime, a lock. None knows there is a child, only a device. None can grant minutes earned on one screen for use on another. No vendor publishes an interface a household can use.

With Handrail

Every vendor keeps its own app and its own design. Each speaks one plan and returns one result, so a budget set once holds across the console, the tablet and the phone. To be certified, the app must meet the standard.
