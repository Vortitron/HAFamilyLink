Platforms will not adopt this out of goodwill; none exposed an age signal until Texas and Utah made them. They adopt it because it is cheaper. Fifteen jurisdictions now name different ages, lists, tests and penalties, and every platform answers every regulator alone. One mark recognised across borders, as IARC is for game ratings, is a competitiveness case a finance ministry will own. The OS vendors are the natural first implementers: they already send a parent-set age band to apps. The ask of them is small.
