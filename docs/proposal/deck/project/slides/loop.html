Trust comes from one rule. A platform must read its own state back and report it honestly. Unknown is reported as unknown, never as unlocked. Certification is self-service on the OpenID pattern: a published test suite, a public registry with level and date, annual re-test, and field audit using synthetic households only. A platform that shows unknown as unlocked above a published threshold gets notice, 90 days to cure and an appeal before delisting. That is what a regulator can audit.
