Who turns this on? A parent or guardian, on the family account they already have, and it covers only the children on that account. There is no ID to set it up and none to switch it off. An adult with no plan is just an adult, and nobody has to prove their age to use the internet. Where a law does set an age, certified apps apply it to child accounts by default, so Handrail complies with a limit. But it does not need one. It was designed for a two year old with a tablet, long before any ban.
