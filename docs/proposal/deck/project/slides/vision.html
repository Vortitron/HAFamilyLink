Here is what a tired parent actually wants. Set the rules once. How long: two hours a day, and it means two hours in total, not two hours on each device. What: which apps and sites are allowed, which sites, topics and words are blocked. When: school apps only on a school day, more at the weekend. Then it holds on every screen, whoever made it. And the child should see the same rule, in the same words, with the reason. Everything else in this deck is how we get there.
