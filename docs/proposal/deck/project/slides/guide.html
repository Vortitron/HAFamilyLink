Parents are tired and do not know every game, so the standard allows an AI guide and makes it optional. Off means off: nothing is sent and the plan works fine without it. Sentry sees only what you tick, like totals and app names, and it can suggest, for example that a bedtime move earlier. It never acts. Control can act, but only inside limits you set, such as granting up to fifteen minutes, and every action is logged and shown to the child. In no mode does it see messages, browsing, location or the child’s name.
